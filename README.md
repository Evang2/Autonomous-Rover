# Autonomous Rover

Embedded C++ autonomous rover using an Arduino UNO R4 WiFi.

## Current progress

- PlatformIO project setup
- L9110S motor driver tested
- Single DC motor forward/reverse control
- PWM speed control
- Minimum starting PWM observed around 100/255

## Planned features

- Four-wheel drive
- Ultrasonic obstacle detection
- Autonomous navigation
- State machine
- Motor calibration
- Sensor filtering
